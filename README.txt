QuestTranslatorPro (퀘스트 번역기 프로) 🍄
==================================================

<img src="https://cdn.buymeacoffee.com/buttons/v2/default-yellow.png" alt="Buy Me A Coffee" style="height: 45px !important;" >

마인크래프트 모드팩 퀘스트, 아이템, 가이드북 전체 통합 AI 번역 솔루션  
복잡한 파일 구조와 코드(색상 코드, 아이템 NBT, 매크로)를 손상시키지 않고 텍스트만 안전하고 완벽하게 번역합니다.

--------------------------------------------------
■ ✨ 핵심 기능
--------------------------------------------------

- ⚡ 120만 개+ 초대용량 마스터 캐시 (0.1초 즉시 로딩): 120만 개 이상의 누적 번역 데이터가 탑재되어 있어, 유명 모드팩 번역 시 98~99.9%의 문장을 API 비용 0원(무료, 초고속)으로 즉각 완성합니다.
- 🎮 인게임 실시간 오역 수정기 (Hotpatching): 게임을 끄지 않고 앱에서 번역을 수정한 뒤 마인크래프트에서 'F3 + T'만 누르면 즉시 번역이 반영됩니다.
- 📦 모드팩 전체 한글화: 수백 개의 모드 JAR에서 '.lang', '.json', 'Patchouli' 책 데이터를 자동 추출하여 원클릭으로 통합 리소스팩을 생성합니다.
- 🎨 스마트 마인크래프트 서식 보존: '&a', '§c', 헥스 컬러('&#RRGGBB'), 매크로 등 특수 서식을 원문 대조로 정밀 복원하여 퀘스트 창 튕김 및 서식 깨짐을 원천 방지합니다.
- 🏷️ 아이템 괄호 병기 최적화: "철 곡괭이 (Iron Pickaxe)"처럼 한글 번역 뒤에 원본 영어를 괄호로 병기하여 JEI/EMI 검색 및 조합 편의성을 극대화합니다.
- 🚀 초고속 묶음(Batch) 번역 엔진: 무료 API에서도 토큰을 효율적으로 묶어 기존 대비 3배 이상의 고속 번역을 제공합니다.
- 🌐 글로벌 클라우드 번역 메모리: Append-Only 구조의 안전한 클라우드 동기화로 다른 유저들이 번역한 최신 데이터가 실시간 공유됩니다.
- 🤖 다중 AI 엔진 지원: Gemini, OpenAI(ChatGPT), DeepL, Google Translate, Local AI(Ollama 등) 지원.
- 📂 스마트 모드팩 자동 인식: CurseForge, Prism Launcher, MultiMC의 인스턴스 폴더를 자동 스캔하여 모드팩 썸네일과 함께 한눈에 관리합니다.

--------------------------------------------------
■ 🎮 프로그램 사용 방법
--------------------------------------------------

▶ 1단계: 실행 및 모드팩 스캔
1. 'QuestTranslatorPro.exe'를 실행합니다. (Windows SmartScreen 경고 시 "추가 정보" ➡️ "실행" 클릭)
2. 상단의 [인스턴스 루트 경로 찾기] 버튼을 눌러 모드팩들이 설치된 런처 폴더를 선택합니다.
    CurseForge: 'C:\Users\[사용자명]\curseforge\minecraft\Instances'
    Prism Launcher / MultiMC: '[설치경로]\instances'
3. 하단에 스캔된 모드팩 카드 목록에서 번역할 모드팩을 클릭합니다.

▶ 2단계: 번역 방식 선택
모드팩 카드를 클릭하면 나타나는 두 가지 번역 버튼 중 원하는 방식을 선택합니다:
 '퀘스트 번역': 모드팩의 퀘스트 파일(FTB Quests, Better Questing 등)만 골라 빠르게 번역하여 즉시 적용합니다.
 '모드팩 전체 번역': 모드 내 아이템/블록 이름('.lang'/'.json')과 가이드북(Patchouli 등)까지 모드팩 전체를 통합 리소스팩으로 일괄 번역합니다.

▶ 3단계: AI 번역 엔진 및 API 키 발급/설정
지원하는 번역 엔진 목록과 각 엔진별 API 키 무료 발급 및 사용 방법입니다:

- 1. 🌟 Google Gemini (가장 추천 / 무료 & 초고속)
 특징: 무료 티어(Free Tier)를 기본 제공하며, 묶음(Batch) 번역을 지원하여 대량 퀘스트 번역에 가장 빠르고 적합합니다.
 발급 방법:
  1. Google AI Studio (https://aistudio.google.com/)에 접속하여 구글 계정으로 로그인합니다.
  2. 좌측 메뉴의 "Get API key"를 클릭한 후 "Create API key" 버튼을 누릅니다.
  3. 생성된 키를 복사하여 프로그램의 API 키 입력란에 붙여넣습니다.
 플랜 선택: 기본 제공되는 무료 키는 [무료 플랜], 신용카드를 등록한 종량제 키는 [유료 플랜 (초고속)]을 선택하세요.

- 2. OpenAI (ChatGPT)
 특징: 'gpt-4o-mini', 'gpt-4o' 등 뛰어난 한국어 문맥 번역 품질을 제공합니다. (소액 유료 결제/크레딧 필요)
 발급 방법:
  1. OpenAI Platform (https://platform.openai.com/api-keys)에 로그인합니다.
  2. "Create new secret key" 버튼을 눌러 새 키를 생성하고 복사합니다.
  3. 프로그램에 API 키를 입력하고 원하는 모델(예: 'gpt-4o-mini')을 선택합니다.

- 3. DeepL
 특징: 번역 전문 엔진으로 문맥이 아주 매끄럽습니다.
 발급 방법:
  1. DeepL API 가입 페이지 (https://www.deepl.com/pro-api)에서 DeepL API Free 플랜(매월 50만 자 무료)에 가입합니다.
  2. 계정 관리 페이지의 [계정(Account)] 탭 하단에서 인증 키(Authentication Key)를 복사하여 프로그램에 입력합니다.

- 4. Local AI (Ollama / LM Studio) - 100% 무료 & 오프라인
 특징: 외부 API 비용이나 토큰 제한 없이, 내 컴퓨터의 GPU 성능을 활용하여 완전 무료/오프라인으로 번역합니다.
 입력 칸 안내 (Local AI 선택 시 3개 입력 칸으로 확장):
   로컬 AI 엔진('Local AI (Ollama/LM Studio)' 또는 'Custom API (OpenAI 호환)')을 선택하면 기존 API 키 단일 입력란 대신 3개의 전용 입력란이 나타납니다:
    1. 커스텀 API 주소 (Base URL): 로컬 AI 서버의 엔드포인트 URL
    2. 모델 이름 (필수): 로컬 프로그램에 로드된 AI 모델의 이름
    3. API 키 (선택사항): 로컬 AI는 인증 키가 필요 없으므로 비워두세요. (사설 유료 프록시 서버 사용 시에만 입력)

 LM Studio 사용 방법:
  1. LM Studio 공식 홈페이지 (https://lmstudio.ai/)에서 프로그램을 다운로드하여 설치합니다.
  2. 상단 검색창에서 한국어 번역 성능이 좋은 모델을 검색하여 다운로드합니다. (추천: 'Qwen2.5', 'Llama-3.1', 'DeepSeek' 등 GGUF 모델)
  3. 좌측 탭에서 Developer(개발자) / Local Server 아이콘('<->')을 클릭합니다.
  4. 상단에서 다운로드한 모델을 로드(Load)한 뒤, "Start Server" 버튼을 눌러 서버를 가동합니다. (기본 포트: '1234')
  5. 퀘스트 번역기에서 아래와 같이 입력합니다:
      커스텀 API 주소: 'http://localhost:1234/v1'
      모델 이름: LM Studio 상단에 로드된 모델 식별자 (예: 'qwen2.5-7b-instruct')
      API 키: 비워두기

 Ollama 사용 방법:
  1. Ollama 공식 홈페이지 (https://ollama.com/)에서 설치합니다.
  2. 터미널(PowerShell 또는 CMD)에서 원하는 모델을 다운로드 및 실행합니다:
      ollama run qwen2.5:14b
  3. 퀘스트 번역기에서 아래와 같이 입력합니다:
      커스텀 API 주소: 'http://localhost:11434/v1'
      모델 이름: 다운로드한 모델명 입력 (예: 'qwen2.5:14b', 'llama3.1')
      API 키: 비워두기

▶ 4단계: 인게임 적용
 퀘스트 번역: 완료 후 원본 모드팩에 바로 덮어쓰거나 ZIP으로 저장할 수 있습니다.
 모드팩 전체 번역: 모드팩의 'resourcepacks/' 폴더에 '[모드팩이름][Korean].zip' 리소스팩이 자동 생성됩니다. 게임 내 [설정] ➡️ [리소스 팩]에서 해당 팩을 우측 최상단으로 올리고 적용하세요.

--------------------------------------------------
■ 🛠️ 인게임 실시간 오역 수정기 ('F3 + T')
--------------------------------------------------

게임을 플레이하다가 어색한 번역이나 오타를 발견했을 때 게임을 종료할 필요가 없습니다.

1. 앱 메인 화면 상단의 '[✏️ 인게임 오역 수정기]' 버튼을 클릭합니다.
2. 수정하고 싶은 단어나 문장을 검색하여 올바른 번역으로 고친 뒤 [저장] 버튼을 누릅니다.
3. 마인크래프트 게임 창으로 돌아와 키보드의 'F3 + T'를 누르면, 리소스팩이 새로고침되며 게임 재접속 없이 즉시 수정된 번역이 인게임에 반영됩니다!
4. 수정된 내용은 로컬과 클라우드에 안전하게 보존됩니다.

■ 📁 퀵 번역 및 퀘스트 모드별 파일 안내 (드래그 앤 드롭)
--------------------------------------------------

앱 상단의 점선 영역에 퀘스트 파일 또는 압축 파일('.zip')을 드래그 앤 드롭하면 모드팩 전체를 스캔할 필요 없이 해당 퀘스트만 즉시 개별 번역할 수 있습니다. 각 퀘스트 모드별로 아래 파일을 찾아 넣어주세요:

 FTB Quests:
   경로: '[모드팩 폴더]\config\ftbquests\quests'
   넣는 방법: 'chapters' 폴더 전체를 ZIP으로 압축해서 넣거나, 'lang/en_us.snbt' 언어 파일이 있는 경우 해당 '.snbt' 파일 하나만 끌어다 넣으면 됩니다.
 Better Questing:
   경로: '[모드팩 폴더]\config\betterquesting'
   넣는 방법: 'DefaultQuests.json' 파일 하나만 끌어다 넣거나, 'DefaultQuests' 폴더 전체를 압축해서 넣으면 됩니다.
 HQM (Hardcore Questing Mode):
   경로: '[모드팩 폴더]\config\hqm'
   넣는 방법: 'quests.hqm' 단일 파일을 찾아 그대로 끌어다 넣으면 됩니다.  
   ⚠️ 주의: HQM은 번역 적용 전 모드팩을 먼저 1회 실행하여 퀘스트북을 열고, 인게임 언어를 '한국어'로 바꾼 뒤에 적용해야 정상 반영됩니다.
 Project Intelligence (드라코닉 에볼루션 등 매뉴얼):
   인게임 태블릿을 한 번 열어 매뉴얼을 로컬로 내려받은 뒤 툴을 번역해주셔야 해당 매뉴얼 한글화가 적용됩니다.

■ 🤝 번역본 파일 공유 방법 (친구 및 커뮤니티)
--------------------------------------------------

▶ 방법 1. 모드팩 번역 캐시 파일 공유 (강력 추천 🌟)
전체 캐시(수백 MB)를 주고받을 필요 없이, 내가 번역한 모드팩의 캐시 파일 딱 1개만 전달하는 가장 가볍고 깔끔한 방법입니다.

1. 공유자 (보내는 사람):
    'dist/translation_modpack/' 폴더로 이동합니다.
    공유할 모드팩 파일(예: 'translation_memory_modpack_StaTech_Industry_2.json')을 복사하여 친구나 커뮤니티에 전달합니다.
2. 수신자 (받는 사람):
    GitHub 최신 릴리즈 페이지 (https://github.com/TEiBA38/QuestTranslato/releases/latest)에서 최신 프로그램을 다운로드받고 압축을 풉니다.
    전달받은 '.json' 파일을 자신의 'dist/translation_modpack/' 폴더 안에 넣습니다.
    'QuestTranslatorPro.exe'를 실행하고 해당 모드팩을 번역하면, API 호출 0회, 100% 즉시 완벌 번역이 완성됩니다!

▶ 방법 2. 완성된 통합 리소스팩 파일 공유
상대방이 번역기 프로그램을 실행할 필요 없이 게임에 바로 적용하게 하고 싶을 때 사용합니다.

1. 번역이 완료된 모드팩의 'resourcepacks/' 폴더로 이동합니다.
2. 자동 생성된 '[모드팩이름][Korean].zip' 파일(예: 'StaTech Industry 2[Korean].zip')을 전달합니다.
3. 받는 사람은 이 ZIP 파일을 자신의 마인크래프트 'resourcepacks/' 폴더에 넣고 인게임 리소스팩 목록에서 활성화하면 됩니다.
