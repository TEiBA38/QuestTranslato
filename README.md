## ✨ 핵심 기능

- **⚡ 148만 개+ 초대용량 마스터 캐시 (0.1초 즉시 로딩)**: 148만 개 이상의 누적 번역 데이터가 탑재되어 있어, 유명 모드팩 번역 시 98~99.9%의 문장을 API 비용 0원(무료, 초고속)으로 즉각 완성합니다.
- **🔒 공식 한글패치 및 고품질 데이터 보호**: 모드 내장 공식 한글패치(`ko_pack`)와 사용자가 직접 교정한 고품질 번역이 일반 AI 번역으로 덮어씌워지는 현상을 원천 방어합니다.
- **🎮 인게임 실시간 오역 수정기 (Hotpatching)**: 게임을 끄지 않고 앱에서 번역을 수정한 뒤 마인크래프트에서 **`F3 + T`만 누르면 즉시 번역이 반영**되며, 4가지 상황별 인게임 반영 가이드 모달을 제공합니다.
- **⚡ 동일 단어 일괄 치환 & 단어 삭제**: 검색된 수십~수백 개 텍스트에서 특정 오역 단어를 한 번에 치환하거나, 공백(' ') 입력으로 불필요한 단어를 깔끔하게 일괄 삭제할 수 있습니다.
- **📦 모드팩 전체 한글화**: 수백 개의 모드 JAR에서 `.lang`, `.json`, `Patchouli` 책 데이터를 자동 추출하여 원클릭으로 통합 리소스팩을 생성합니다.
- **🎨 스마트 마인크래프트 서식 보존**: `&a`, `§c`, 헥스 컬러(`&#RRGGBB`), 매크로 등 특수 서식을 원문 대조로 정밀 복원하여 퀘스트 창 튕김 및 서식 깨짐을 원천 방지합니다.
- **🏷️ 아이템 괄호 병기 최적화**: "철 곡괭이 (Iron Pickaxe)"처럼 한글 번역 뒤에 원본 영어를 괄호로 병기하여 JEI/EMI 검색 및 조합 편의성을 극대화합니다.
- **🚀 초고속 묶음(Batch) 번역 엔진**: 무료 API에서도 토큰을 효율적으로 묶어 기존 대비 3배 이상의 고속 번역을 제공합니다.
- **🌐 글로벌 클라우드 번역 메모리**: Append-Only 구조의 안전한 클라우드 동기화로 다른 유저들이 번역한 최신 데이터와 공식 키가 실시간 공유됩니다.
- **🤖 2026 최신 다중 AI 엔진 지원**: Google AI(Gemini), OpenAI(ChatGPT), Anthropic(Claude), DeepSeek(딥시크), Local AI(Ollama / LM Studio) 지원.
- **🔍 로컬 AI 원클릭 모델 자동 감지**: LM Studio 및 Ollama 서버에서 구동 중인 모델을 원클릭으로 자동 탐색하여 드롭다운에 즉시 등록합니다.
- **📂 스마트 모드팩 자동 인식**: CurseForge, Prism Launcher, MultiMC의 인스턴스 폴더를 자동 스캔하여 모드팩 썸네일과 함께 한눈에 관리합니다.

## 🎮 프로그램 사용 방법

### 1단계: 실행 및 모드팩 스캔
1. `QuestTranslatorPro.exe`를 실행합니다. *(Windows SmartScreen 경고 시 "추가 정보" ➡️ "실행" 클릭)*
2. 상단의 **[인스턴스 루트 경로 찾기]** 버튼을 눌러 모드팩들이 설치된 런처 폴더를 선택합니다.
   * **CurseForge**: `C:\Users\[사용자명]\curseforge\minecraft\Instances`
   * **Prism Launcher / MultiMC**: `[설치경로]\instances`
3. 하단에 스캔된 모드팩 카드 목록에서 번역할 모드팩을 클릭합니다.

### 2단계: 번역 방식 선택
모드팩 카드를 클릭하면 나타나는 두 가지 번역 버튼 중 원하는 방식을 선택합니다:
* **`퀘스트 번역`**: 모드팩의 퀘스트 파일(FTB Quests, Better Questing 등)만 골라 빠르게 번역하여 즉시 적용합니다.
* **`모드팩 전체 번역`**: 모드 내 아이템/블록 이름(`.lang`/`.json`)과 가이드북(Patchouli 등)까지 모드팩 전체를 통합 리소스팩으로 일괄 번역합니다.

### 3단계: AI 번역 엔진 및 API 키 발급/설정
번역 엔진 선택 창 우측의 **`[ℹ️ AI 모델 정보]`** 버튼을 누르면 각 엔진별 무료/유료 여부, 일일 제한량(RPD), 그리고 감지된 파일 100개당 예상 비용(USD/KRW)을 언제든지 비교할 수 있습니다.

#### 1. 🌟 Google AI (Gemini) - 가장 추천 / 무료 & 초고속
* **특징**: 무료 티어(일 1,500회)를 기본 제공하며, 묶음(Batch) 번역을 지원하여 대량 퀘스트 번역에 가장 빠르고 경제적입니다.
* **추천 모델**:
  * `gemini-3.5-flash-lite (가성비 추천)`: 무료 일 1,500회 제공, 초고속 처리 속도와 준수한 번역 품질
  * `gemini-3.8-flash (고품질 추천)`: 최신 플래그십 엔진으로 마인크래프트 고유 명사 및 뉘앙스 번역 품질 극대화
* **발급 방법**:
  1. [Google AI Studio](https://aistudio.google.com/)에 접속하여 구글 계정으로 로그인합니다.
  2. 좌측 메뉴의 **"Get API key"**를 클릭한 후 **"Create API key"** 버튼을 누릅니다.
  3. 생성된 키를 복사하여 프로그램의 **API 키** 입력란에 붙여넣습니다.
* **플랜 선택**: 기본 무료 키는 **[무료 계정 (안전대기 / 10 RPM 속도제한)]**, 결제 카드를 등록한 종량제 키는 **[유료 계정 (초고속·고품질 번역 / 제한없음)]**을 선택하세요.

#### 2. OpenAI (ChatGPT) - 선불 크레딧 충전 필수
* **특징**: 최고 수준의 문맥 이해도와 매끄러운 한국어 문체 번역을 제공합니다.
* **추천 모델**:
  * `gpt-6-luna (가성비 추천)`: 백만 토큰당 $0.10/$0.50 수준의 극가성비 모델 (100파일 약 100~300원)
  * `gpt-6.1-terra (고품질 추천)`: 최상위권 번역 품질과 합리적 가격의 밸런스형 모델
* **발급 방법**:
  1. [OpenAI Platform](https://platform.openai.com/api-keys)에 로그인합니다.
  2. Billing 메뉴에서 선불 크레딧($5 이상)을 충전합니다.
  3. API keys 메뉴에서 **"Create new secret key"** 버튼을 눌러 새 키를 생성하고 프로그램에 입력합니다.

#### 3. Anthropic (Claude) - 선불 크레딧 충전 필수
* **특징**: 전 세계 개발자 및 번역가들이 극찬하는 최고 수준의 정교한 문맥 번역 및 자연스러운 어휘 구사력을 자랑합니다.
* **추천 모델**:
  * `claude-haiku-5-5 (가성비 추천)`: 백만 토큰당 $0.10/$0.50의 초저비용 초고속 모델
  * `claude-sonnet-5-5 (고품질 추천)`: 마인크래프트 모드 특유의 판타지 뉘앙스까지 완벽하게 소화하는 명품 번역
* **발급 방법**:
  1. [Anthropic Console](https://console.anthropic.com/)에 로그인합니다.
  2. Plans & Billing에서 선불 크레딧을 충전합니다.
  3. API Keys 메뉴에서 키를 발급받아 프로그램에 입력합니다.

#### 4. DeepSeek (딥시크) - 선불 크레딧 충전 필수
* **특징**: 압도적인 가성비와 강력한 추론/코딩 번역 성능을 제공하며, 한국 시간 기준 비피크 시간대(01:30~09:30) 이용 시 50% 할인 혜택이 적용됩니다.
* **추천 모델**:
  * `deepseek-flash (가성비 추천)`: 백만 토큰당 $0.15/$0.60의 극가성비 번역
  * `deepseek-v4-pro (고품질 추천)`: 복잡한 퀘스트 스토리 및 가이드북 설명 번역에 최적화
* **발급 방법**:
  1. [DeepSeek Platform](https://platform.deepseek.com/)에 로그인합니다.
  2. Top up 메뉴에서 충전 후, API Keys 메뉴에서 키를 생성하여 프로그램에 입력합니다.

#### 5. Custom API (Local AI 등) - 100% 무료 & 오프라인 & 원클릭 모델 감지
* **특징**: 외부 API 비용이나 토큰 제한 없이, 내 컴퓨터의 GPU 성능을 활용하여 완전 무료/오프라인으로 번역합니다.
* **🔍 모델 자동 감지 기능 탑재**: Base URL 입력 후 **`[🔍 모델 감지]`** 버튼을 누르면 현재 로컬 서버에 구동 중인 모델(예: `qwen2.5:14b`, `llama3.1` 등)을 프로그램이 자동으로 감지하여 선택지에 등록합니다.
* **LM Studio 사용 방법**:
  1. [LM Studio](https://lmstudio.ai/) 실행 ➡️ 상단 검색창에서 GGUF 모델 다운로드 (추천: `Qwen2.5`, `Llama-3.1`).
  2. 좌측 Developer 탭(`<->`) ➡️ 모델 로드(Load) ➡️ **"Start Server"** 클릭 (기본 포트 `1234`).
  3. 퀘스트 번역기에서 커스텀 API 주소에 `http://localhost:1234/v1` 입력 후 **`[🔍 모델 감지]`** 버튼 클릭!
* **Ollama 사용 방법**:
  1. [Ollama](https://ollama.com/) 설치 후 터미널에서 실행: `ollama run qwen2.5:14b`
  2. 퀘스트 번역기에서 커스텀 API 주소에 `http://localhost:11434/v1` 입력 후 **`[🔍 모델 감지]`** 버튼 클릭!

* **퀘스트 번역**: 완료 후 원본 모드팩에 바로 덮어쓰거나 ZIP으로 저장할 수 있습니다.
* **모드팩 전체 번역**: 모드팩의 `resourcepacks/` 폴더에 `[모드팩이름][Korean].zip` 리소스팩이 자동 생성됩니다. 게임 내 **[설정] ➡️ [리소스 팩]**에서 해당 팩을 우측 최상단으로 올리고 적용하세요.

## 🛠️ 인게임 실시간 오역 수정기 (`F3 + T`)

게임을 플레이하다가 어색한 번역이나 오타를 발견했을 때 게임을 종료할 필요가 없습니다.

1. 앱 메인 화면 상단의 **`[✏️ 인게임 오역 수정기]`** 버튼을 클릭합니다.
2. **검색 & 필터링**:
   * 상단 검색창에서 영어 원문이나 한글 번역문 키워드로 즉시 검색할 수 있습니다.
   * `통합`, `영어 원문만`, `한글 번역만` 필터 및 최대 검색 건수(500개~전체)를 자유롭게 설정할 수 있습니다.
   * 모드 내장 공식 한글패치나 바닐라 공식 데이터는 **`🔒공식`** 배지로 안전하게 구별됩니다.
3. **듀얼 편집 모드**:
   * **`[ 🛠️ 번역 직접 수정 ]`**: 선택한 단일 항목의 번역문을 원하는 문구로 정교하게 수정하고 저장합니다.
   * **`[ ⚡ 동일 단어 일괄 치환 ]`**: 여러 항목을 체크 선택한 뒤, 특정 오역 단어를 한 번에 일괄 치환합니다. '바꿀 단어'에 공백(' ')을 입력하면 해당 단어가 문장에서 완전히 삭제됩니다.
   * **`[ 🤖 선택 항목 AI 재번역 ]`**: 여러 항목을 체크 선택한 뒤 메인 화면에 세팅된 최신 AI 모델로 일괄 재번역하며, 원문·기존 번역·AI 재번역이 한 줄로 정리된 비교 로그를 확인한 후 원클릭 적용(O/X)할 수 있습니다. (바닐라 공식 명칭은 자동 보호)
4. **💡 인게임 반영 가이드 모달**:
   * 수정기 상단의 **`[💡 인게임 반영 가이드]`** 버튼을 누르면 마인크래프트 상황별 즉시 새로고침 방법(퀘스트 모드별 리로드 명령어, 리소스팩 `F3 + T` 단축키, 패출리 책 리로드, LAN 치트 열기 등)을 바로 열람할 수 있습니다.
5. 저장 즉시 로컬 캐시와 클라우드 번역 메모리에 영구 보존됩니다.

## 📁 퀵 번역 및 퀘스트 모드별 파일 안내 (드래그 앤 드롭)

앱 상단의 점선 영역에 퀘스트 파일 또는 압축 파일(`.zip`)을 드래그 앤 드롭하면 모드팩 전체를 스캔할 필요 없이 해당 퀘스트만 즉시 개별 번역할 수 있습니다. 각 퀘스트 모드별로 아래 파일을 찾아 넣어주세요:

* **FTB Quests**:
  * **경로**: `[모드팩 폴더]\config\ftbquests\quests`
  * **넣는 방법**: `chapters` 폴더 전체를 ZIP으로 압축해서 넣거나, `lang/en_us.snbt` 언어 파일이 있는 경우 해당 `.snbt` 파일 하나만 끌어다 넣으면 됩니다.
* **Better Questing**:
  * **경로**: `[모드팩 폴더]\config\betterquesting`
  * **넣는 방법**: `DefaultQuests.json` 파일 하나만 끌어다 넣거나, `DefaultQuests` 폴더 전체를 압축해서 넣으면 됩니다.
* **HQM (Hardcore Questing Mode)**:
  * **경로**: `[모드팩 폴더]\config\hqm`
  * **넣는 방법**: `quests.hqm` 단일 파일을 찾아 그대로 끌어다 넣으면 됩니다.  
  * ⚠️ *주의: HQM은 번역 적용 전 모드팩을 먼저 1회 실행하여 퀘스트북을 열고, 인게임 언어를 '한국어'로 바꾼 뒤에 적용해야 정상 반영됩니다.*
* **Project Intelligence (드라코닉 에볼루션 등 매뉴얼)**:
  * 인게임 태블릿을 한 번 열어 매뉴얼을 로컬로 내려받은 뒤 툴을 번역해주셔야 해당 매뉴얼 한글화가 적용됩니다.

## 🤝 번역본 파일 공유 방법 (친구 및 커뮤니티)

### 방법 1. 모드팩 번역 캐시 파일 공유 (강력 추천 🌟)
전체 캐시(수백 MB)를 주고받을 필요 없이, 내가 번역한 모드팩의 캐시 파일 딱 1개만 전달하는 가장 가볍고 깔끔한 방법입니다.

1. **공유자 (보내는 사람)**:
   * `dist/translation_modpack/` 폴더로 이동합니다.
   * 공유할 모드팩 파일(예: `translation_memory_modpack_StaTech_Industry_2.json`)을 복사하여 친구나 커뮤니티에 전달합니다.
2. **수신자 (받는 사람)**:
   * [GitHub 최신 릴리즈 페이지](https://github.com/TEiBA38/QuestTranslato/releases/latest)에서 최신 프로그램을 다운로드받고 압축을 풉니다.
   * 전달받은 `.json` 파일을 자신의 **`dist/translation_modpack/`** 폴더 안에 넣습니다.
   * `QuestTranslatorPro.exe`를 실행하고 해당 모드팩을 번역하면, **API 호출 0회, 100% 즉시 완벌 번역**이 완성됩니다!

### 방법 2. 완성된 통합 리소스팩 파일 공유
상대방이 번역기 프로그램을 실행할 필요 없이 게임에 바로 적용하게 하고 싶을 때 사용합니다.

1. 번역이 완료된 모드팩의 `resourcepacks/` 폴더로 이동합니다.
2. 자동 생성된 **`[모드팩이름][Korean].zip`** 파일(예: `StaTech Industry 2[Korean].zip`)을 전달합니다.
3. 받는 사람은 이 ZIP 파일을 자신의 마인크래프트 `resourcepacks/` 폴더에 넣고 인게임 리소스팩 목록에서 활성화하면 됩니다.

프로그램 폴더 내 핵심 구성 요소입니다:
